# Unit U2: release.yml mac 腿 + workflow 结构断言

> 泳道：2（workflow，串行）　映射：AC1、AC4、AC5（T9/T10/T11/T12/T13）

## 目标
`.github/workflows/release.yml` **仅追加** mac 腿（不删改既有 linux/windows/docker/release/merge 任何行为——AC5/T11 静态断言守护）。

## 契约
- 新增 `binaries-macos` job：`runs-on: macos-15`（单机，Q1 裁决）；步骤 = checkout → rustup target add（aarch64-apple-darwin + x86_64-apple-darwin）→ Swatinem/rust-cache → `cargo build --release --target <t> -p cloudmount-daemon -p cloudmount-cli`（顺序步双 target，**不采用 matrix**——gate1 MINOR① 裁决收紧）→ 调用 `scripts/package-macos.sh` → upload artifact（glob `cloudmount-darwin-*.tar.gz`，`if-no-files-found: error`）
- release job：`needs` 仅追加 `binaries-macos`（不删既有依赖）；不带 `if:`/status 函数覆盖（T11）
- Release body 产物表补 mac 行：**无 Developer ID 签名/公证（arm64 产物为链接器 ad-hoc 签名，Apple Silicon 运行所需）** + Gatekeeper 绕过指引（`xattr -cr` 或右键→打开）
- `on:` 保持仅 `push: tags: v*`（R2-MAJOR 裁决：check job 不落本文件，零 dispatch 副作用）

## TDD 红绿路径
1. **红**：先写 `scripts/release-yaml.test.sh`（grep 式结构断言，Git Bash 可跑）覆盖 T9（binaries-macos job 存在+runner=macos-15+双 target 字面+非 matrix 顺序步形态）/T10（调用 package-macos.sh+upload glob `cloudmount-darwin-*.tar.gz`+`if-no-files-found: error`）/T11（release needs 含 binaries-macos+无 `if:`/status 覆盖）/T12（产物表 mac 行+签名精确措辞+Gatekeeper 指引）/T13（actionlint release.yml 过——不可用时降级 YAML 解析并记缺口；另对注入语法错误的副本验证拦截有效）——改 release.yml 前必红；提交。
2. **绿**：修改 release.yml 至断言全绿；**测试断言零修改**；提交。

## 验收
- 结构断言脚本全绿 + actionlint（可用时）零错
- `git diff` 核对：既有 job 字面零删改，纯追加
