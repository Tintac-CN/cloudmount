# Unit U1: mac 打包脚本（关键路径）

> 泳道：1（脚本关键路径）　映射：AC2、AC3②③部分（T1/T2/T3/T4/T5、T8 文档面）

## 目标
`scripts/package-macos.sh`——mac 双架构 tar.gz 打包单一事实来源（CI 与本地 dry-run 同脚本同代码路径）。

## 契约（红测以此为准，实现不得弱化）
- 用法：`package-macos.sh --bin-dir <产物目录> --out <输出目录> [--dry-run]`；dry-run 以占位二进制运行，产物只写 `<out>/dry-run/` 专属子目录，与真实上传路径隔离（prd.md 错误处理边界）
- `set -euo pipefail`：任一步失败整体非零退出，无半成品目录/空 tar 残留
- 必含文件硬校验（缺任一立即失败，不产出 tar）：`cloudmountd`、`cloudmount`（须可执行）+ `README.md`、`edge.md`——与 linux 腿对文档静默容错不同，mac 腿硬校验（AC2 必有内容）
- tar 布局：根级四文件拍平（对齐 linux 腿 `cd dist && tar czf … .` 形态），不含 `packaging/systemd/*` 与任何 desktop 条目
- 输出命名：`cloudmount-darwin-<arch>.tar.gz`（`<arch>` ∈ `aarch64|x86_64`，Q2 裁决）
