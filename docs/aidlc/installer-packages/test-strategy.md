## 分层策略

- **单元**：新结构断言脚本 `scripts/installers-yaml.test.sh`（本地 Git Bash 直跑，静态 grep/awk 断言 release.yml+安装器定义文件；T1-T14）。测：MSI/pkg job 存在与结构（runner/命名）、产物命名严格匹配、upload `if-no-files-found: error`+artifact name 前缀、needs 门控+零删改护栏+无 `if:`/status/`continue-on-error` 覆盖、范围排除（desktop/服务注册/launchd）、`prerelease: true`/`draft: true` 负断言、on: 守护、脚本自身交付（独立文件+TDD 红→锁→绿+防空真/CRLF 剥除/计数诚实）。不测：真实 MSI/pkg 构建、真实安装行为、runner 真实执行（既有 job 结构由上 intent 锁定脚本守护；新脚本承接既有产物名锚点/既有 job 名作双保险，允许对被修改面做包含式护栏——M1 裁决）。
- **集成**：actionlint 整文件校验+注入语法错误自校验（不可用降级 python YAML 解析/键配平，T15）；条件性本地 WiX 冒烟（T16，P0，Construction 首日工具链验证——MSI 安装行为唯一 tag 前验证路径；SKIP 需显式人工裁决留痕，M5）。不测：GitHub Actions 真实调度语义（needs 门控行为依赖平台语义，静态断言其结构前提：needs 在位+无覆盖字面）。
- **E2E**：线上人工（release.yml 仅 tag `v*` 触发、PR 不跑——安装包产物只能 tag 后核验）：T17/T19 Release 资产+体积带；T18 MSI 静默装/PATH/卸载（执行环境=本机 Windows，属线上产物人工核验）；T20 pkg 真机安装（需真 mac 机；降级判据 M6 钉死）；T21 正式 Release 语义+既有资产零删改；T22 UI 安装冒烟（P2）。人工核验清单固化见缺口节（首个含安装包的 tag 即真实发布）。

- [ ] **【缺口·E2E 不可自动化】MSI/pkg 真实安装行为无法 CI 自动验证**（release.yml 仅 tag 触发，PR 不跑）。MSI 核验执行环境=本机 Windows（下载后 msiexec 静默装/卸可本地执行，T18）；mac pkg 安装只能真 mac 机（T20）——**降级判据（M6 钉死）：无 mac 机时降级为资产完整性核验=pkg 文件头 magic `xar!` 校验+体积带复核，记缺口；真机补验触发条件（借到真机时执行 T20 全项）入发布 SOP**。**人工核验清单（固化载体=operations 新 runbook，gate1 钉死——取代声明式清单）**：**第 0 步（gate2 准出回填 MINOR 9 补）：tag 前复核 release.yml 触发器仅 `push: tags: ["v*"]`（无 workflow_dispatch——T13 守护）+ 手动触发 `check-macos.yml`（workflow_dispatch）确认编译面绿**；① Release 资产含 `cloudmount-windows-x64.msi`+双 arch pkg，可下载，体积带复核；② MSI：**管理员权限 shell 前置**（MINOR⑤ 补——msiexec /qn 为 Machine 级安装）→`msiexec /i /qn`→Program Files\CloudMount 两 exe 在位→安装后 OS 新开终端 PATH 生效→SmartScreen 提示为预期→`msiexec /x /qn` 卸载干净（文件+PATH）；③ pkg：真机 `installer -pkg`→/usr/local/bin 两文件在位可执行→Gatekeeper 拦截为预期（右键打开/`xattr -cr` 解除）→卸载干净；④ 产物表含 MSI/pkg 行+签名状态说明；⑤ 既有资产仍在（零删改）。
