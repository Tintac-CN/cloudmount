## 目标
mac pkg 安装包全链路：打包脚本 + release.yml job + Release 集成。

## 契约
- `scripts/package-pkg-macos.sh`（沿 package-macos.sh 先例）：
  - `set -euo pipefail`；用法 `--bin-dir <产物目录> --out <输出目录> [--dry-run] [--arch aarch64|x86_64]`
  - staging 归集（mktemp+trap）：cloudmountd/cloudmount（可执行）+ 铺放布局 `staging/usr/local/bin/`（安装目标字面）
  - 前置硬校验（先于一切产出）：两二进制 `-x`+存在性——缺任一非零退出不产出
  - **dry-run 仅覆盖 staging+硬校验段**（prd R2-MAJOR-1 边界：pkgbuild 调用段 mac 独占、本地不覆盖——dry-run 模式下校验后即退出 0，不调 pkgbuild）
  - pkgbuild 调用：`pkgbuild --root <staging> --identifier io.github.tintac-cn.cloudmount --version <github.ref_name 传入值> <out>/cloudmount-darwin-<arch>.pkg`（identifier=MINOR⑫ 落位）
  - 头注释：用法+dry-run 边界+CI 调用形态
- release.yml 新增 `installer-pkg-macos` job（仅追加）：
  - `runs-on: macos-15`（已钉）；顺序步双 target（沿 binaries-macos 先例：rustup targets+rust-cache+双 `cargo build --release --target <t> -p cloudmount-daemon -p cloudmount-cli`）
  - 每 target 归集 staging 后调 `scripts/package-pkg-macos.sh --arch <短arch>`（版本经 `--version "${GITHUB_REF_NAME#v}"` 类适配传入——v 前缀适配本 unit 落字面）
  - upload：path 为**双字面精确路径**（`cloudmount-darwin-aarch64.pkg` 与 `cloudmount-darwin-x86_64.pkg`，不用 glob）+`if-no-files-found: error`+artifact name `cloudmount-` 前缀
  - release `needs` 追加本 job；body 产物表追加 pkg 每 arch 一行+Gatekeeper 引导
- **不含** launchd/preinstall/postinstall/desktop（T8 负断言在盯）；`on:` 零改动。
