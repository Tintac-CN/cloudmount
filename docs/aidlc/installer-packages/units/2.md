## 目标

## 契约
- `packaging/wix/main.wxs`（手写，Q2 裁决）：
  - 双 File 组件：cloudmountd.exe、cloudmount.exe → `ProgramFilesFolder`+`Name="CloudMount"`
  - Machine 级 PATH：`Environment` 元素（`System="yes"`、Part="last"、PATH）
  - ARP 条目（WiX 缺省）；**Manufacturer=`tintac-cn`**（MINOR⑫ 落位——安装器元数据统一取 GitHub 实际 owner，Cargo.toml repository=zhonghaoxi 为历史不一致不流入）
  - ProductVersion 取 `github.ref_name`（v 前缀与数值格式适配——job 步内 sed/参数处理；rc tag 撞格式走构建失败 fail-safe）
  - UTF-8：中文 description 流入 ARP 的风险——首日验证定（UTF-8 BOM 或 ARP 描述改英文）
  - **不含** ServiceInstall/desktop（T4 负断言在盯）
- release.yml 新增 `installer-msi-windows` job（仅追加，既有 job 零删改）：
  - `runs-on: windows-latest`（Windows runner pin 本 unit 落字面）
  - 步骤：checkout → rust-toolchain → **Swatinem/rust-cache**（构建来源=job 内重编译，MINOR⑫ 落位——不下载 binaries-windows artifact）→ `cargo build --release -p cloudmount-daemon -p cloudmount-cli` → 前置 .exe 存在性校验步 → WiX 构建（**安装方式与版本锁定本 unit 首日定**：v3（choco install wixtoolset）vs v4/v5（dotnet SDK）——定后锁版本写注释）→ upload（path `cloudmount-windows-x64.msi`、`if-no-files-found: error`、artifact name `cloudmount-` 前缀）
  - release job `needs` 追加本 job；body 产物表追加 MSI 行+签名说明（SmartScreen 引导）+安装侧提示三关键词（新开终端/UAC/先卸载再装）
- `on:` 零改动；无 `prerelease:`/`draft:` 键。
