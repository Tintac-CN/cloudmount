# Unit U7: F-06 RdcWatcher 真释放

> 映射：AC6 / T-09、T-10　依赖：无　泳道 3

## 目标
Drop 真正回收线程与目录句柄（现状 `drop(self.handle.clone())` 净变化为零，每次引擎重建泄漏）；有界收割防 Drop 永久挂起。

## 触及文件
- `crates/cloudmount-sync/src/rdc.rs`：
  - `RawHandle` 增 `close(&self)`（`closed: AtomicBool` 守卫，`swap(true)` 成功才 `CloseHandle`；drop 复用同守卫，防 OS 句柄值复用误关）
  - `RdcWatcher` 字段改 `handle: Option<Arc<RawHandle>>`、`thread: Option<JoinHandle<()>>`、新增 `exited: Arc<AtomicBool>`（event_loop 三个退出出口归一置位）
  - `Drop`：`shutdown.store(true)` → `handle.take().close()`（唤醒阻塞读，尽力而为）→ 轮询 exited（50ms，上限 5s）→ join；超时 detach + `tracing::warn!`（决策 #13）
  - 模块级 `ACTIVE_WATCHERS: AtomicUsize`（**spawn 成功后立即 +1**；event_loop 退出 `-1` 用 `saturating_sub`——防 scan_tree 失败路径下溢）+ `#[doc(hidden)] pub fn active_watcher_count()`
