## 目标

## 触及文件
- `crates/cloudmount-daemon/src/webdav.rs`：
  - **F-08**（:595-621）：`WriteFileWithProvider` 增 `flushed: bool`；flush 幂等护栏 → 锁内 flush → `guard.take()`（作用域结束关句柄）→ 上传 → `remove_file`（删除失败 `tracing::warn!` 记路径后**接受残留**，不掩盖上传结果）；新增 `impl Drop`：关句柄 + `!flushed` 时删 spool 残留（PUT 中途断连自愈）；flushed 于上传确认成功后置位
  - **F-09**（:291-309）：`Err(_)` 收窄为 `Err(FsError::NotFound) => 合成新条目`；`Err(e) => return Err(e)`（dav-server 映射 5xx）
