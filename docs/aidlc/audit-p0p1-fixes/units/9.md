# Unit U9: F-01 水合分块（P0）

> 映射：AC1 / T-01、T-02　依赖：无　泳道 4

## 目标
CfAPI 水合不再全量读入内存（4GB 视频 → 4GB Vec 的 OOM 根因）：HydrateFn 改分块推送契约，内存峰值 = 1 块（1 MiB）。

## 触及文件
- `crates/cloudmount-vfs/src/backends/cfapi.rs`：`HydrateFn` 契约改为 `Box<dyn Fn(&str, u64, u64, &mut dyn ChunkSink) -> Result<()> + Send + Sync>`（新增 `trait ChunkSink { fn transfer(&mut self, offset: u64, data: &[u8]) -> Result<()>; }`）；`fetch_data_callback`（:729-756）构造 sink：每块先查 `ctx.cancelled`（取消 → Err 停止并 drop reader）→ `transfer_data(info, offset, Some(chunk), 0)`；水合日志移到最后一块成功后整体记录
- `crates/cloudmount-vfs/src/backends/cfapi_mount.rs`：水合闭包（:113-139）——寻址与范围钳制不变；`open_range` **仅调用一次**，`pump_chunks(reader, sink, chunk)` crate 内可测函数循环读单个复用 1 MiB 缓冲逐块推送；`const HYDRATION_CHUNK = 1 MiB`；`CF_HYDRATION_POLICY_FULL` 不变（决策 #8）
- `crates/cloudmount-vfs/tests/cfapi_hydration.rs`：两处调用点（:188/:243）机械适配新签名
