# Unit U8: F-07 锁内计划/锁外执行

> 映射：AC7 / T-11、T-12　依赖：无　泳道 3

## 目标
`ensure_remote_dir` 不再持 `dir_ids` 全局锁做网络 IO（弱网不阻塞全部事件），同时保住"并发不重复建远端目录"安全性设计（exec.rs:9）。

## 触及文件
- `crates/cloudmount-sync/src/exec.rs`：两阶段重构——
  1. 锁内只做计划：沿 `rel` 组件走 `dir_ids` map → 得已解析 ID 与缺失前缀链 `Vec<(prefix, comp)>` → 立即放锁
  2. 锁外执行：`dir_creating: Mutex<HashMap<String, Arc<Mutex<()>>>>` per-前缀锁（锁序父先子后，无环）→ 双检 `dir_ids` → 仍缺失才 `provider.list`/`create_dir` → 写回（并顺手移除 `dir_creating` 已完成条目防无界增长）
